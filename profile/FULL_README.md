# Valkyrja

[Valkyrja][valkyrja url] is a framework for web and console applications.

Valkyrja (pronounced "Valk-ear-ya") is the Old Norse spelling for Valkyrie, a
mythical creature that would guide warriors to Valhalla after death. In a
similar sense, the Valkyrja framework guides your application to be in a
better state — fast, light, and robust, doing the heavy lifting so you can
focus on what you're building.

Get Started
-----------

Valkyrja is available in multiple languages. Start here:

- **PHP** — [valkyrja-php][valkyrja-php url] _(production — reference
  implementation)_
- **Java** — [valkyrja-java][valkyrja-java url] _(in progress)_

Or start a new application directly:

- **PHP** — [valkyrja-starter-app-php][starter-php url] — use "Use this
  template" or `composer create-project valkyrja/application your-project`
- **Java** — [valkyrja-starter-app-java][starter-java url] — in progress

The Ecosystem
-------------

Surrounding the framework are tools, integrations, and shared conventions:

- **Build tool** — [sindri-php][sindri url] — scaffolds applications and
  generates cache files for faster runtime performance
- **Worker runtimes** — persistent-worker integrations for production:
  [OpenSwoole][openswoole url], [FrankenPHP][frankenphp url],
  [RoadRunner][roadrunner url] _(PHP)_; [Netty][netty url],
  [Jetty][jetty url], [Tomcat][tomcat url] _(Java)_
- **Docker** — [valkyrja-docker-php][docker url] — ready-made containers for
  running Valkyrja applications
- **Architecture** — [architecture][architecture url] — design decisions and
  port planning across all languages
- **Shared tooling** — CI configurations, templates, and conventions live in
  dedicated repos in this organization

Explore the full list in the [repositories tab][org repos url].
